# Security policy

## Supported versions

| Version | Support |
|---------|---------|
| **0.5.x** | Current HACS release |
| **0.4.x and older** | Upgrade to **0.5.0** |

## Reporting a vulnerability

Do not open a public GitHub issue for a security vulnerability.

Email the maintainer listed on [github.com/bjorngluck](https://github.com/bjorngluck), or use [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) on [bjorngluck/piherder-ha](https://github.com/bjorngluck/piherder-ha) if it is enabled.

Include what the issue is, how to reproduce it, the card version, and whether you plan a public write-up.

This card only polls a PiHerder herder. Herder vulnerabilities belong on [bjorngluck/piherder](https://github.com/bjorngluck/piherder) ([SECURITY.md](https://github.com/bjorngluck/piherder/blob/main/SECURITY.md)).
